# 전자잉크에서 글자 크기 테스트

서버 배포 후 기존 펌웨어와 구글 중계로 사용할 수 있습니다.

1. KEY를 2초 길게 눌러 휴대폰 설정에 연결합니다.
2. 화면 모드를 **큰 메모**로 선택합니다.
3. 큰 메모 입력칸에 아래 명령 중 하나를 넣고 저장합니다.

| 입력 | 전자잉크에 표시되는 화면 |
| --- | --- |
| 글자테스트 | 18·20·22·24px 비교 |
| 글자테스트 18 | 18px로 채운 한 페이지 |
| 글자테스트 20 | 20px로 채운 한 페이지 |
| 글자테스트 22 | 22px로 채운 한 페이지 |
| 글자테스트 24 | 24px로 채운 한 페이지 |

대시보드의 메모 1·2가 아니라 **큰 메모** 입력칸을 사용합니다.
기존 큰 메모 내용이 필요하면 다른 곳에 복사해 둡니다.
하단 버튼이 ‘저장하고 대시보드로 돌아가기’여도 선택한 큰 메모 모드가 적용됩니다.

모든 테스트 화면은 Pretendard Regular(400), 좌우 여백 24px, 줄 간격 1.5배입니다.
기존 SVG 렌더링·흑백 변환·EPD2 전송 과정을 그대로 거치므로 실제 패널에서 판단할 수 있습니다.
비교 페이지와 개별 크기 페이지 모두 빨강을 사용하지 않습니다.
시각과 배터리 변화도 표시하지 않아 같은 테스트를 주기적으로 받으면 동일한 화면 데이터가 나옵니다.
다만 펌웨어의 정기 전체 갱신 정책은 그대로 적용됩니다.

테스트 시작 시 기존 화면의 빨강을 지우기 위해 전체 갱신이 발생할 수 있습니다.
KEY를 짧게 누르면 기존 기능대로 대시보드로 돌아갑니다.
크기 변경은 KEY를 길게 눌러 다시 설정에 들어간 뒤 명령을 바꿔 저장합니다.
이번 기능은 글자 크기 비교용이며, KEY로 책 페이지를 넘기는 기능은 아직 추가하지 않았습니다.

일반 문장을 저장하면 기존 큰 메모 화면으로 동작합니다.
시계 모드나 대시보드에서는 위 명령을 테스트 명령으로 해석하지 않습니다.

검증: `node --test tests/memo-font-test.test.mjs`
- 실제 렌더러로 5개 테스트 화면 생성, 48,000바이트 흑백/빨강 데이터 확인
- 빨강 데이터 전체 흰색, 시각·배터리가 달라도 테스트 화면 데이터 동일
- 기존 POST API에서 96,032바이트 EPD2 생성 및 양쪽 CRC 검사
- 캘린더·날씨·시세 호출 없이 동작
- 실제 패널에서 최종 크기·가독성 판단 필요
