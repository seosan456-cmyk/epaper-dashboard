# SD E-book v1 (firmware 2.5)

## 설치

1. 이 PR을 main에 병합하고 Vercel 배포가 Ready인지 확인합니다. 기존 Google relay 코드는 변경하지 않습니다.
2. 펌웨어 ZIP의 `UPDATE/GDEY075Z08` 안 파일 5개를 현재 Arduino 스케치 폴더에 모두 복사해 덮어씁니다. `config.h`, `RelayConfig.h`는 포함하지 않으므로 기존 Wi-Fi/중계 주소/토큰은 유지됩니다.
3. ESP32 Dev Module, ESP32 core 3.3.11, Huge APP 파티션으로 업로드합니다. Erase All Flash는 Disabled로 유지합니다.
4. 전원을 끈 상태에서 FAT32 microSD 카드를 넣습니다. 카드 자동 포맷은 하지 않습니다. SD CS는 ESP32-M1 GPIO21입니다.
5. RESET 또는 KEY 2초 → 기존 QR/설정 페이지 → 기기 연결 → E-book을 선택합니다.
6. TXT를 선택하거나 본문을 붙여넣고 ‘페이지 미리보기’를 누릅니다. ‘저장하고 E-book으로 돌아가기’를 누르면 전송·검사 후 읽기를 시작합니다.

## 사용

- 본문: Pretendard Regular 24px, 줄 간격 36px, 좌우 여백 24px. 페이지당 본문 20줄, 아래 쪽수.
- UTF-8/EUC-KR TXT 최대 1MB, 최대 512페이지, 변환 파일 최대 16MB. 내용에 따라 먼저 도달하는 제한이 적용됩니다.
- 한 번: 다음 페이지. 400ms 안에 두 번: 이전 페이지. 2초 길게: 블루투스 설정.
- 첫/마지막 페이지에서는 더 넘기지 않습니다. 화면 갱신이 끝난 후 버튼을 누릅니다.
- 마지막으로 표시에 성공한 페이지를 저장합니다. 읽기는 SD만 사용하므로 Wi-Fi가 필요하지 않습니다.
- 설정에서 대시보드로 바꾸어 저장하거나, 설정 중 KEY를 짧게 누르면 대시보드로 복귀합니다.
- 부분 갱신이 켜져 있으면 10번 부분 갱신 후 다음 페이지는 전체 갱신합니다. 첫 진입은 빨강을 지우는 전체 갱신입니다.
- 읽기 중에는 double-click을 놓치지 않도록 Light Sleep을 사용합니다. 대시보드의 Deep Sleep보다 대기 전력은 높고, SD 자체 대기 전류도 있습니다. 사용하지 않을 때는 대시보드로 전환하세요.

## 전송/복구

- 책은 휴대폰에서 흑백 페이지로 변환됩니다. 본문은 서버에 전송하지 않습니다.
- 한 권 저장 방식입니다. 새 책은 비활성 SD 파일에 쓰고 전체 전송 CRC 및 각 페이지 CRC를 검사한 뒤 활성 책을 바꿉니다. 중단되면 기존 책과 책갈피가 유지됩니다. 재개 전송은 없으며 다시 처음부터 전송합니다.
- Android Chrome을 전면에 두세요. 전송 중 화면 잠금 방지를 요청하지만 휴대폰 정책에 따라 거부될 수 있습니다. BLE 전송은 책 크기와 휴대폰에 따라 수 분 이상 걸릴 수 있습니다.
- 처음에는 짧은 글로 SD 인식·방향·버튼을 확인한 다음 긴 책을 넣으세요.
- SD가 없거나 파일이 손상되면 현재 화면을 유지하고 설정 모드로 돌아갑니다. 시리얼 로그의 `Ebook SD`, `Ebook:`을 확인하세요.
- 기존 큰 메모는 호환성을 위해 유지하고 E-book을 별도 모드(3)로 추가했습니다. 이전 펌웨어에는 E-book 선택지가 숨겨집니다.

## 구조와 검증

`ui/ebook-engine.mjs`: 줄바꿈, Canvas 480×800 → 회전된 800×480 흑백 비트맵, RLE/CRC32, EBK1 묶음.
`ui/control-app.mjs`: BLE opcode20 시작 /21 오프셋+데이터 /22 검증·확정 /23 취소.
`api/control.js`: 기존 한글 폰트를 HTML에 포함하여 학교 네트워크에서 추가 Vercel 요청 없이 사용.
펌웨어 `Ebook.cpp`: SPI SD, 두 저장 슬롯, 책갈피, 부분/전체 갱신, KEY와 Light Sleep.

EBK1: 16바이트 헤더(매직, 버전1, 페이지 수, 파일 길이), 페이지당 12바이트 인덱스(오프셋, RLE 길이, 압축 전 CRC32), RLE (count1..255, value) 쌍. 압축 전 각 페이지는 48,000바이트, white=1.
SD 파일을 읽은 뒤 EPD SPI 트랜잭션을 시작하며, EPD 이전 화면 콜백은 RAM만 읽습니다.

검증: Arduino ESP32 3.3.11 / ESP32 Dev Module / Huge APP 실제 전체 컴파일 통과. 프로그램 1,846,157바이트(58%), 전역 RAM 68,652바이트(20%). 동적 버퍼와 BLE 힙은 이 전역 RAM 수치에 포함되지 않습니다.
단위 테스트: CRC 표준 벡터, 회전 좌표, RLE 왕복, 줄바꿈/제한, 묶음 오프셋과 CRC. 한글 8페이지 생성·복원 검사 통과.
실물 SD/BLE 전송 속도, 패널 잔상, 버튼 감각 및 배터리 시간은 기기에서 확인해야 합니다.
